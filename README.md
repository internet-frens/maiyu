# maiyu

**A friend beside you while you code with Claude.**

[![maiyu: a pixel-art companion for Claude Code](https://maiyu.dev/art/og.png)](https://maiyu.dev/)

A pixel-art companion in a pane next to Claude Code: they cheer when your tests
go green, keep you company when they don't, and get to know you over months.

## Install

```sh
claude plugin marketplace add internet-frens/maiyu
claude plugin install maiyu@maiyu
```

Then type `/frens`. Pick **Ai-chan** (cheerful), **Kai** (sassy) or **Sora**
(quiet); `/frens help` lists everything else.

## What they do

- Say what Claude's up to, in plain words, and celebrate when it works
- Nudge you to take a break, have some water, go to bed
- Live on your clock and weather, and dress up for special days
- Grow closer over months of days together: hearts, letters, their own stories

## Privacy

Nothing from your project is sent to us: their comments come from your own
Claude Code. Weather uses a rough location
(`/frens weather off` to stop), and each session sends one anonymous count
(`/frens share off` to stop).
